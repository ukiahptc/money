# 빚 갚는 가계부

대출 800만원 완납을 목표로 한 가계부·소비 계획 웹앱입니다. 아이폰 우선으로 설계했고, 서버 없이 브라우저(localStorage)에 데이터를 저장합니다.

## 진행 현황

| 섹션 | 내용 | 상태 |
|---|---|---|
| 1. 대출 관리 | 대출 정보 입력, 상환 스케줄, 추가 상환 시뮬레이션, 목표 완납 계산 | 완료 |
| 2. 가계부 | 수입·지출 기록·수정·삭제, 월별 조회, 카테고리별 집계·필터 | 완료 |
| 3. 소비 계획 | 카테고리별 월 예산, 예산 대비 지출 진행바, 남는 돈 → 추가 상환 제안, 카테고리 편집 | 완료 |
| 4. 대시보드 | 대출 잔액 진행률·완납 예정, 이번 달 가계·예산 현황, 6개월 지출 추이, 최근 내역 | 완료 |
| 5. 백업·배포 | JSON 백업 내보내기·불러오기, CSV 내보내기, 홈 화면 앱(PWA)·오프라인, GitHub Pages | 완료 |

## 파일 구조

```
index.html                  화면 뼈대 + 하단 탭바
manifest.json / sw.js       홈 화면 앱(PWA) 설정, 오프라인 캐시
icons/                      앱 아이콘
css/style.css               스타일 (라이트/다크 모드)
js/utils.js                 숫자 포맷, DOM 생성, 월 이동 바, 하단 시트
js/storage.js               localStorage 저장/불러오기/교체
js/loan.js                  대출 상환 계산 (순수 함수)
js/ledger.js                가계부 카테고리(편집 가능), 월별 조회·집계
js/budget.js                예산 집계, 추가 상환 제안
js/backup.js                JSON/CSV 내보내기, JSON 불러오기, 전체 삭제
js/views/loan-view.js       대출 관리 화면
js/views/ledger-view.js     가계부 화면
js/views/budget-view.js     소비 계획 화면 + 카테고리 편집 시트
js/views/dashboard-view.js  대시보드 + 데이터 백업 카드
js/app.js                   탭 전환, 서비스 워커 등록
```

## 로컬에서 보기

`index.html`을 더블클릭해 브라우저로 열면 됩니다. (이 방식에서는 오프라인 캐시만 동작하지 않습니다.)

## GitHub Pages 배포 (아이폰에서 쓰기)

1. GitHub 저장소 페이지 → 상단 **Settings** 탭 → 왼쪽 메뉴 **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: 배포할 브랜치 선택(예: `main`), 폴더: **/ (root)** → **Save**
4. 1~2분 뒤 같은 화면 상단에 `https://<아이디>.github.io/money/` 주소가 뜹니다.
5. 아이폰 Safari로 그 주소를 열고 → 하단 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**

홈 화면 아이콘으로 열면 주소창 없이 앱처럼 뜨고, 한 번 연 뒤에는 인터넷이 없어도 열립니다.

파일을 고친 뒤에는 `sw.js`의 `CACHE` 버전 문자열(예: `money-v5` → `money-v6`)을 올려야 아이폰에 저장된 옛 파일이 새 파일로 바뀝니다.

## 데이터 보관·이동

- 모든 데이터는 **기기 브라우저(localStorage)에만** 저장됩니다. 서버에 올라가지 않습니다.
- PC↔아이폰으로 옮기려면 대시보드 맨 아래 **JSON 백업 내보내기** → 파일을 다른 기기로 전달(에어드롭·카카오톡 등) → **JSON 백업 불러오기**.
- 아이폰 Safari는 홈 화면 앱을 오래 안 열면 저장 데이터를 지울 수 있으니, 가끔 JSON 백업을 내보내 두는 편이 안전합니다.
- CSV는 엑셀용 가계부 내보내기 전용이고 불러오기는 지원하지 않습니다.

## 대출 여러 건 다루기

- 첫 실행 시 **신용 대출(800만원)**과 **비상금 대출(금액 미입력)** 카드가 생깁니다. 비상금 대출 카드에 잔액·금리·기간을 채우면 됩니다.
- 이미 쓰던 기기라면 대출 탭 맨 아래 **+ 대출 추가**를 눌러 카드를 만들고 이름을 '비상금 대출'로 바꾸면 됩니다.
- 맨 위 녹색 카드와 대시보드는 모든 대출을 합산합니다. 가계부의 '대출 상환' 카테고리는 대출을 구분하지 않으므로, 구분이 필요하면 메모에 어느 대출인지 적어 두세요.
- 소비 계획의 "추가 상환 가능액"은 금리·기간이 입력된 **첫 번째 대출**에 적용됩니다. 보통 금리가 높은 대출(비상금 대출이 더 높은 경우가 많음)을 먼저 갚는 편이 유리하니, 그 대출을 카드 순서상 위에 두세요.

## 계산 기준

- 월 이자 = 잔액 × 연 금리 ÷ 12 (원 단위 반올림)
- 추가 상환액은 매달 원금에 바로 반영되며, 월 정기 납입액은 유지한 채 **기간이 단축**되는 방식으로 계산합니다.
- 은행의 일할 계산·중도상환수수료는 반영하지 않으므로 실제 청구액과 차이가 있을 수 있습니다.

## 가계부 카테고리

- 지출: 식비, 카페·간식, 교통, 주거·관리비, 통신, 구독, 쇼핑, 생활용품, 의료·건강, 문화·여가, 경조사·선물, 자기계발, 대출 상환, 기타
- 수입: 급여, 부수입, 환급·캐시백, 기타
- 소비 계획 탭 → **카테고리 편집**에서 이름 변경·순서 이동·추가·삭제할 수 있습니다. '기타'와 '대출 상환'은 삭제할 수 없습니다(집계·대출 연동에 사용).
- 삭제한 카테고리의 기록과 예산은 '기타'로 옮겨집니다.

## 대시보드 계산 기준

- **남은 대출**: 대출 탭에 입력한 잔액에서 상환 스케줄(추가 상환 포함)대로 지난 달까지 갚았다고 가정한 예상 잔액. 실제와 다르면 대출 탭 잔액을 고치면 됩니다.
- **추가 상환 가능액**(소비 계획 탭): 이번 달 수입(없으면 최근 3개월 중 가장 최근 수입) − 예산 합계.
